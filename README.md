# 🛒 ShopSphere - E-Commerce Web App

A responsive e-commerce web application built using React.  
Users can browse products, add items to cart, manage wishlist, and search products.

---

## 🚀 Live Demo
https://shopsphere-app.netlify.app/

---

## 📌 Features

- 🔍 Search products
- 🛍️ Add to Cart
- ❤️ Add to Wishlist
- ➕ Increase / Decrease Quantity
- ❌ Remove items from Cart/Wishlist
- 📱 Fully Responsive (Mobile + Desktop)
- 🔄 Real-time UI updates

---

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6)
- Tailwind CSS
- React Router DOM
- Fake Store API
